# Premiere Timeline Pan

An AutoHotkey script that lets you pan the timeline in Adobe Premiere Pro.

## Download

[**Download Premiere Timeline Pan (.ahk)**](https://github.com/Ammar-A7med/premiere-timeline-pan/raw/refs/heads/main/premiere-timeline-pan.ahk)

## Run on Windows Startup

If you want the script to launch automatically when Windows starts, place the script in the following folder:

```text
%userprofile%\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup
```

You can open this folder using **Windows + R** or directly through **File Explorer** by pasting the path into the address bar.
