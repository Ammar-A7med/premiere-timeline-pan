# Premiere Timeline Pan

سكريبت AutoHotkey بيتيحلك تحريك الـ Timeline في Adobe Premiere Pro.

## تشغيل السكريبت مع بدء تشغيل الويندوز

لو عايز السكريبت يشتغل تلقائيًا مع بداية تشغيل الويندوز، حط ملف السكريبت في المسار ده:

```text
%userprofile%\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup
```

تقدر تفتح المسار ده عن طريق **Windows + R** أو من خلال **File Explorer** عادي، بأنك تحط المسار في شريط العنوان.
